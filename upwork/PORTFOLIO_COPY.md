## Project 1 — ClientOps

**Title**

Sales Pipeline Dashboard with Filtering, Metrics, and CSV Export

**Role**

Independent builder — AI-assisted implementation, product decisions, testing, and final QA

**Description**

I built ClientOps as a focused sales pipeline workspace for a small team that needs to see momentum and next actions without wrestling with a large spreadsheet.

The responsive dashboard combines pipeline value, active leads, win rate, overdue follow-ups, stage distribution, and a detailed opportunity list. Users can search by company or contact, filter by stage, source, and owner, sort the results, inspect each lead in a side drawer, and export the currently filtered view to CSV.

The project includes validated API routes, URL-synced filters, loading and no-results states, responsive table-to-card behavior, and automated tests for query parsing, metrics, pagination, sorting, endpoint responses, and CSV escaping.

All 60 records are synthetic. No real customer data is used.

**Skills**

Next.js, TypeScript, API Development, Cloudflare Workers, Cloudflare D1, Dashboard Design, Data Visualization, Responsive Web Design, CSV, Software Testing

## Project 2 — BacaDengar

**Title**

Local-First Android Reading and Listening App

**Role**

Independent builder — AI-assisted implementation, architecture review, testing, and final QA

**Description**

BacaDengar is a private Android application designed for continuity across long-form reading and listening sessions. It supports local EPUB, PDF, TXT, and audio content while preserving reading positions, playback progress, bookmarks, themes, and font preferences.

The app uses Kotlin and Jetpack Compose for the interface, Room for local persistence, Media3 for playback, WorkManager for background work, and coroutines for asynchronous operations.

The public case study explains the product decisions, architecture, and engineering challenges without exposing the private repository or copyrighted reading content. The project has been verified with its Gradle unit-test and debug-build workflow.

**Skills**

Kotlin, Android, Jetpack Compose, Room Database, Media3, WorkManager, Coroutines, Mobile App Development, Software Testing
